小鲸鱼桌宠 · 便携版
====================

怎么用
------
双击  WhalePet.exe

不需要装 Python，不需要装 PySide6，也不需要装 DSH 插件。
整个文件夹拷到任何 Windows 10 / 11 电脑上都能直接跑，路径随便放（桌面 / D 盘 / U 盘都行）。

没有开机自启，也不会往注册表里写任何东西 —— 想启动就双击，不想用就关掉。

> 首次运行 Windows 可能提示"未知发布者"（未签名），点「更多信息 → 仍要运行」即可。


设置从哪开（只从任务栏）
------------------------
**左键点、右键点任务栏右下角的托盘图标**（那只小鲸鱼）—— 两种都**直接开设置面板**。

（没有二级菜单：退出、显示/隐藏、各项开关都收在面板里，所以不设菜单也不会丢入口。）

**在她身上点右键不会有任何反应** —— 设置入口刻意只留在托盘，
免得随手点到她就弹面板。左键点她、拖她照常。

面板会**弹在鼠标光标上方**，所以从托盘点开时贴着任务栏（跟系统托盘菜单一样）。

> 找不到托盘图标？Windows 默认会把新出现的托盘图标收进任务栏那个「^」小箭头里。
> 点开「^」找到小鲸鱼，**按住拖到任务栏上**就固定住了，以后一直在外面。


怎么关掉
--------
托盘图标右键 → 「退出」
或设置面板最下面的「退出」


她会做什么
----------
· 蹲在屏幕角落，隔一会儿自己冒一句怪话
· 按下去响一声，松开响一声
· 单击：弹一下 + 回你一句
· 双击：立刻冒一句
· 按住拖动：拖到任意位置，松手会吸附屏幕边缘
· 右键她：**没有反应**（设置只走托盘图标）


设置面板里有什么
----------------
  说一句            立刻让她冒一句
  ─────────────
  说话频率          闭嘴 / 安静 / 正常 / 话多 / 话痨
  大小              滑块，180 ~ 460 px，拖着当场变大变小
  形象              切换形象（有几个就列几个）
  音效              开启 / 试听 / 切换音效组 / 音量滑块
  其他              总在最前 / 锁定位置 / 鼠标穿透
                    形象目录 / 音效目录 / 编辑台词
                    重载台词 / 回到右下角 / 显示·隐藏 / 退出


嫌她吵？调「说话频率」
---------------------
    闭嘴      完全不主动说话（点她回嘴、拖她、各项确认提示照旧）
    安静      5 ~ 15 分钟才冒一句（**默认**）
    正常      1.5 ~ 3.5 分钟
    话多      30 ~ 70 秒
    话痨      8 ~ 20 秒

两点说明：

- **「闭嘴」和「安静」这两档，启动时也不会打招呼**。之前是不管哪档、
  一开机必说一句，安静档照样被吵到 —— 这次一起修了。
- 改了档位**立刻生效**，不用等上一轮的定时器到点。


记住你的设置（全部）
--------------------
下面这些改过之后会**自动记住**，下次打开还是你上次的样子：

    位置 / 大小 / 形象 / 音效组 / 音量 / 音效开关 / 说话频率
    总在最前 / 锁定位置 / 鼠标穿透

都存在同目录的 `config.json` 里，是个纯文本文件，可以直接用记事本改。

- **删掉 `config.json` = 恢复出厂设置**（位置回到右下角、形象回到自带的那只…）
- 每次启动就会写一次，退出时再写一次，所以不存在"改了没记住"
- 唯一**故意不记**的是「隐藏桌宠」——不然下次打开你什么都看不见，
  容易以为程序坏了；她总是会出现的


锁定位置
--------
面板「其他」里的「**锁定位置**」勾上之后，她就钉在原地拖不动了
—— **点她、右键她、逗她全都照常**，只是拖不走，防止手滑拖跑。

再点一下取消勾选就解锁。


鼠标穿透（置顶时也能点到底下的东西）
------------------------------------
面板「其他」里的「**鼠标穿透**」勾上之后，她虽然还在最前面显示，
但**鼠标点她会直接穿到后面的窗口上** —— 也就是完全不挡你操作。

- 想恢复：**点托盘图标 → 「鼠标穿透」再点一次**
  （开着穿透时面板里第一项就是「关闭鼠标穿透」，专门给你找回来的）
- 状态会记住，下次启动还是这个设置

一句话：想安心把她摆在屏幕角落又不挡事，就开穿透 + 锁定位置。


贴到左边会自动镜像
------------------
把她拖到屏幕**左半边**，她会自动**水平翻转**过去：

  · 形象翻转（头发、蝴蝶结、腮红全跟着翻）
  · 气泡也翻转（泡体和尾巴跑到另一侧，尾巴照样指着她）
  · **台词文字仍然是正着读的**，不会变成一堆左右反的字

拖回右半边就自动恢复。这跟余额插件里
「贴左吸附时整体水平镜像翻转（文字同步反向）」是同一个行为
—— 插件用的招是"整体翻一次、文字再翻一次抵消"，这里等价实现。

不想要这个效果：用记事本打开 config.json，把 `"mirror_left"` 改成 `false`。


换形象：一个形象一个文件夹
--------------------------
在 assets\skins\ 下建一个文件夹，**文件夹名就是面板里显示的名字**，
里面放：

    assets\skins\我的角色\
        char.png       纯角色（透明底）—— 必须，程序画的就是这张
        bubble.png     含对话框的整图 —— 可选，只是文件规范

放好后打开设置面板，「形象」那一段就会多出一个按钮，点一下立刻换。
**不影响原来的形象**，可以来回随便切，跟音效也是各切各的。

为什么建议放两张？这是插件自己的约定：原插件就是
DSniang1.png（纯角色裁切图）+ DSniang02.png（含空白气泡的整图）。
**渲染只用纯角色那张** —— 气泡是代码画的，所以台词多长都能自适应，
不会被图片里那个固定大小的气泡挤爆。第二张留着当参考，
以后想自己做气泡造型时可以照着画。

> 图省事也可以只丢一张散图：assets\skins\我的角色.png，一样认。
> 文件名不一定要叫 char，character / 角色 / 本体 也行。


换音效：一个音效组一个文件夹
----------------------------
在 assets\sounds\ 下新建文件夹（文件夹名 = 面板里显示的名字），里面放：

    assets\sounds\我的音效\
        press.mp3      （或 .wav / .m4a / .ogg，按下去响的）
        release.mp3    （松开响的）

两个都放最好；只放一个也能用，另一个不响。
打开设置面板，「音效」那一段就会多出一个按钮，点一下立刻换，
**不影响原来的音效**，也可以和形象自由组合。


台词（核心玩法）
----------------
用记事本打开 lines.json：

    "lines"       自己冒出来的怪话，一行一句
    "click_lines" 戳她时的回应，一行一句

改完保存，托盘右键 → 「重新载入台词」，不用重启。


文件夹里都是什么
----------------
WhalePet.exe      程序本体
_internal\        Qt 和 Python 运行库（别删，删了就跑不起来）
assets\skins\     形象（一个文件夹一个形象）
assets\sounds\    音效组（一个文件夹一组）
lines.json        台词库
config.json       第一次运行后自动生成（位置 / 大小 / 当前形象与音效）
pet.pid           运行时会生成，关掉自动删
LICENSE.txt       MIT 许可（本程序以 MIT 发布）
THIRD-PARTY-NOTICES.txt
                  第三方声明：参考了哪个项目、哪些素材不能再分发

--------------------------------
assets\ 里自带两类素材：

  1. 角色形象（skins\DSniang\）—— **基于上游角色形象的二次创作图**，
     不是本项目原创，**不在 MIT 许可范围内**。自用没问题，正式发布或商用
     建议换成你自己拥有完整权利的作品。
  2. 合成音效（sounds\default\）—— 本项目的原创合成音效，以 MIT 发布，
     可以随意替换或再分发。

**程序代码本身**以 MIT 发布，随便用、随便改。

**注意**：本程序参考了 DSH 的余额插件
（github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget，MIT），
但那个插件的**音效不在 MIT 覆盖范围内、不授予再许可**，因此未包含在本程序中。

所以：

  · 你自己从插件里拷那套音效来自己用 —— 没问题
